# Rockify

Rockify permite que un anfitrión con Spotify Premium cree una sala privada y que sus invitados propongan música y voten para saltar la canción actual.

La aplicación se compone de Flutter, una API NestJS, PostgreSQL con Prisma y Socket.IO. Consulta [la guía de producción](docs/GUIA_PRODUCCION.md) antes de ejecutarla.
